# Zero Paint Linux

A non-destructive, GPU-accelerated raster graphics editor.

## Overview
This repository contains the highly-optimized native core for the zero paint linux platform. It is built with zero-cost abstractions, direct hardware access, and massive internal C++ vendoring for algorithmic superiority.

## Key Advantages
- CUDA/Metal hardware rendering
- Deep color depth processing
- Infinite layers.

## Why zero-paint-linux? (Competitive Edge)
**The Problem:** Unlike Photoshop, there are no subscriptions, no cloud telemetry, and image processing is handled purely on the GPU for instant filter execution.

**The Solution:** zero-paint-linux provides an entirely distinct, low-level architectural approach. By discarding heavy runtimes, web-views, and telemetry dependencies, we achieve maximum computational throughput and deterministic execution.
